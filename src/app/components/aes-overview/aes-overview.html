Algorithm Overview

Understanding AES

Advanced Encryption Standard - the symmetric block cipher that secures our digital world.

What is AES?

The Advanced Encryption Standard (AES) is a symmetric block cipher chosen by the U.S. National Institute of Standards and Technology (NIST) in 2001. It replaced the aging DES (Data Encryption Standard) and has become the most widely used encryption algorithm in the world.

AES is based on the Rijndael cipher, designed by Belgian cryptographers Joan Daemen and Vincent Rijmen. The algorithm was selected after a rigorous five-year standardization process that evaluated 15 competing designs.

Symmetric Encryption

AES uses the same key for both encryption and decryption. This differs from asymmetric algorithms like RSA, which use separate public and private keys.

Block Cipher Structure

AES operates on fixed-size blocks of 128 bits (16 bytes). The data is arranged in a 4×4 matrix of bytes called the State. Each byte in the state can be represented as a value from 0 to 255 (0x00 to 0xFF in hexadecimal).

Почему именно 128 бит?

Rijndael (алгоритм, лёгший в основу AES) поддерживал блоки 128, 192 и 256 бит. NIST выбрал фиксированный размер 128 бит как оптимальный компромисс: достаточно большой для безопасности (birthday attack требует 2⁶⁴ блоков), но достаточно маленький для эффективной аппаратной реализации. Размер 4×4 байта идеально ложится на 128-битные SIMD-регистры процессоров.

Почему байты записываются столбцами, а не строками?

Это одна из самых неочевидных деталей AES. Когда вы берёте 16 байт входных данных, они заполняют матрицу состояния по столбцам (column-major order), а не по строкам.

Зачем column-major порядок?

Это сделано для того, чтобы операция MixColumns работала с «правильными» данными. MixColumns обрабатывает каждый столбец матрицы как полином в поле Галуа. Если записывать данные по столбцам, то каждый столбец содержит 4 последовательных байта входа — и MixColumns перемешивает именно их. А ShiftRows, наоборот, сдвигает строки, перемешивая данные между столбцами. Вместе эти две операции обеспечивают полную диффузию — каждый выходной бит зависит от всех входных битов уже после нескольких раундов.

Substitution-Permutation Network (SPN)

AES построен по архитектуре подстановочно-перестановочной сети (SPN). Это означает, что каждый раунд состоит из чередования двух типов операций:

  • Подстановка (Substitution): SubBytes заменяет каждый байт через S-Box. Это создаёт нелинейность — без неё шифр можно было бы взломать системой линейных уравнений.
  • Перестановка (Permutation): ShiftRows и MixColumns перемешивают биты между позициями. Это создаёт диффузию — изменение одного бита входа влияет на все биты выхода.
  • Ключевое смешивание: AddRoundKey XOR-ит состояние с раундовым ключом, внося зависимость от секрета.

Эта архитектура была предложена Клодом Шенноном ещё в 1949 году. Он доказал, что чередование «confusion» (запутывание) и «diffusion» (рассеивание) — необходимые свойства стойкого шифра.

Почему 10 раундов для AES-128?

Количество раундов выбрано с большим запасом прочности. Авторы Rijndael рассчитали, что полная диффузия достигается за 2 раунда. Для стойкости против дифференциального и линейного криптоанализа достаточно ~6 раундов. 10 раундов дают значительный запас безопасности. При этом увеличение ключа до 256 бит требует 14 раундов, чтобы компенсировать атаки по связанным ключам (related-key attacks).

Security Properties

AES achieves its security through two fundamental cryptographic properties:

Confusion

Each bit of the ciphertext depends on multiple bits of the key. The S-Box substitution creates complex, non-linear relationships between input and output.

Diffusion

Each bit of plaintext influences many bits of ciphertext. ShiftRows and MixColumns spread changes across the entire state matrix.

Galois Field GF(2⁸) — Математическая основа

Все операции AES определены в конечном поле Галуа GF(2⁸). Это поле из 256 элементов (по числу возможных значений байта), где определены сложение и умножение с особыми свойствами:

  • Сложение — это обычный XOR. 0x57 + 0x83 = 0xD4. Сложение и вычитание одинаковы (a + a = 0).
  • Умножение — полиномиальное умножение по модулю неприводимого полинома x⁸ + x⁴ + x³ + x + 1 (= 0x11B). Это гарантирует, что результат всегда помещается в байт.

Почему именно этот полином? Он неприводим над GF(2) — его нельзя разложить на множители. Это как простое число, но для полиномов. Из всех неприводимых полиномов степени 8 над GF(2) авторы Rijndael выбрали 0x11B, потому что он даёт наиболее эффективную аппаратную реализацию.

В GF(2⁸) каждый ненулевой элемент имеет мультипликативный обратный — и это ключевое свойство для построения S-Box. Мультипликативный обратный байта b — это такой байт b⁻¹, что b × b⁻¹ = 1 в GF(2⁸).

Key Expansion — Расширение ключа

Из одного 128-битного ключа AES генерирует 11 раундовых ключей (44 четырёхбайтных слова = 176 байт). Каждый раунд использует свой раундовый ключ для операции AddRoundKey.

Алгоритм расширения ключа построен так, чтобы изменение одного бита исходного ключа приводило к изменению примерно половины битов в каждом раундовом ключе — это свойство называется лавинный эффект.
